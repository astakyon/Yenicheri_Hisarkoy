# Yeniçeri: Hisarköy Muhafızı

Osmanlı temalı 3D aksiyon RPG. Tarayıcıda (telefon ve bilgisayar) oynanır, kurulum gerekmez.
Oyun adresi: https://astakyon.github.io/Yenicheri_Hisarkoy/

Sürüm: bkz. `VERSION`. Kaynak `src/` altındadır; `index.html` buradan **üretilir**.

```
python3 tools/build.py     # src/ -> index.html
sh tests/run.sh            # kaynak denetimleri + tarayıcı duman testi
```
